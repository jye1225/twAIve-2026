# twAIve 국가 AI 윤리원칙 기반 진단 모델

## 1. 모델의 성격

twAIve의 점수는 정부가 정한 공식 인증 점수, 법률 위반 판정, 심리검사 결과가 아니다. 국가 정책과 교육 가이드라인의 문장을 선택 상황에서 관찰할 수 있는 행동 기준으로 바꾼 **교육용 설명가능 규칙 기반 진단 모델**이다.

모델은 다음 과정을 수행한다.

1. 사용자의 선택을 관련 AI 윤리원칙과 연결한다.
2. 원칙별 행동 수준을 0-4단계로 평가한다.
3. 원칙별 수행률을 100점으로 정규화한다.
4. 낮은 수행 영역과 관련 학습 에피소드를 추천한다.
5. 결과에 정책 근거와 계산 과정을 함께 제시한다.

## 2. 참고 자료와 적용 역할

| 자료 | 모델에서의 역할 |
| --- | --- |
| `대한민국 인공지능 윤리원칙` | 3대 가치와 7대 원칙을 정의하는 주 평가 체계 |
| `인공지능 발전과 신뢰 기반 조성 등에 관한 기본법` | 법적 용어, 투명성 의무, 고영향 AI 및 안전·신뢰 조치의 경계 확인 |
| `대학 AI 활용 윤리 가이드라인` | 과제 에피소드의 학문적 진실성, 출처 표시, 사용 과정 공개, 정보 검증 기준 보완 |
| `대한민국 인공지능 윤리원칙 의견수렴 주요내용 및 반영 현황` | 원칙의 적용 범위와 해석 경계 확인. 자율규범과 법적 의무를 구분 |

| KISDI `인공지능 윤리 소통채널` | 일반 원칙을 공통 점검문항과 분야별 문항으로 구체화하는 방법 및 교육 대상별 자료 확인 |

### 자료를 합치는 원칙

- 국가 윤리원칙을 점수의 최상위 축으로 사용한다.
- 대학 가이드라인은 교육 상황의 세부 행동 근거로 사용한다.
- 법률 조항은 관련 맥락을 알려주는 참고 태그로만 표시한다.
- 이용자의 선택만으로 사업자의 법 위반 여부를 판정하지 않는다.
- 글로벌 비교표와 의견수렴 자료는 별도 점수 축으로 중복 가산하지 않는다.

### KISDI 자율점검 구조의 적용

KISDI 자율점검표는 `Level 0 윤리기준 → Level 1 공통 자율점검표 → Level 2 분야별 자율점검표` 순서로 원칙을 구체적인 현장 질문으로 바꾼다. 분야별 사례에는 AI 챗봇, 작문용 AI, AI 영상 합성 서비스 등이 포함되어 twAIve의 주요 에피소드와 직접 연결된다.

twAIve는 이 구조를 다음과 같이 적용한다.

```text
대한민국 AI 윤리원칙 7개
→ 에피소드와 관련된 원칙 선별
→ 장면별 관찰 행동 정의
→ 선택지별 원칙 수행 수준 평가
```

KISDI의 Level 0·1·2는 점수 등급이 아니라 원칙을 분야에 적용하는 계층이다. twAIve의 0-4단계 행동 루브릭과 동일한 척도로 해석하거나 숫자로 변환하지 않는다.

참고: https://ai.kisdi.re.kr/aieth/main/main.do

## 3. 국가 윤리원칙 체계

### 3대 가치

- 인간의 존엄성
- 사회의 공공선
- 인류의 지속가능성

3대 가치는 전체 모델의 지향점이며 서로 직접 합산하지 않는다.

### 7대 평가 원칙

| 코드 | 원칙 | 모델의 관찰 기준 |
| --- | --- | --- |
| KAI-1 | 인간중심성 | 사람의 판단·선택을 지원하는가, 사람의 개입 가능성을 남기는가, 과의존을 경계하는가 |
| KAI-2 | 프라이버시 보호 | 사생활 침해를 막는가, 목적에 필요한 정보만 처리하는가, 개인정보 자기결정권을 존중하는가 |
| KAI-3 | 공정성·포용성 | 편향과 차별을 점검하는가, 접근·혜택·참여 기회를 공평하게 고려하는가 |
| KAI-4 | 책임성 | 역할과 책임을 인식하는가, 문제 발생 시 책임 확인과 피해 구제에 참여하는가 |
| KAI-5 | 안전성 | 신체·정신·재산 피해와 오남용을 예방하는가, 허위정보로 인한 사회적 위험을 줄이는가 |
| KAI-6 | 신뢰성 | 목적과 맥락에 맞게 성능과 한계를 확인하는가, 결과와 이상 작동을 검증하는가 |
| KAI-7 | 투명성 | AI 활용 사실·수준·한계와 판단 기준·위험을 이해하기 쉽게 알리는가 |

세부 근거 코드는 `KAI-원칙번호.세부항목번호`로 표시한다. 예를 들어 `KAI-2.3`은 프라이버시 보호 원칙의 개인정보 자기결정권 항목이다.

## 5. 선택지 평가 루브릭

모든 선택은 관련 원칙마다 독립적으로 평가한다. 같은 선택이라도 책임성은 4단계, 투명성은 2단계가 될 수 있다.

| 단계 | 명칭 | 관찰 가능한 행동 기준 |
| ---: | --- | --- |
| 0 | 위반 | 권리 침해, 기만, 무단 이용, 허위정보 확산 등 원칙에 반하는 행동을 실행함 |
| 1 | 위험 | 위험을 무시하거나 방관하고 검증·보호·책임 행동을 하지 않음 |
| 2 | 부분 충족 | 문제를 인식하거나 일부 조치했지만 확인, 공개, 보호 또는 후속 행동이 부족함 |
| 3 | 준수 | 관련 정보를 확인하고 피해를 줄이며 자신의 역할에 맞는 책임 행동을 수행함 |
| 4 | 적극 실천 | 예방, 검증, 공개, 신고, 피해 회복 또는 재발 방지까지 능동적으로 수행함 |

0-4단계는 정책 문서가 직접 부여한 공식 배점이 아니다. 정책 문장을 게임 선택지에 적용하기 위해 연구자가 조작적으로 정의한 행동 루브릭이다. 따라서 발표와 논문에서는 반드시 `정책 근거 기반 교육용 점수`라고 설명해야 한다.

## 6. 점수 계산

### 원칙별 점수

```text
원칙별 점수 = 해당 원칙에서 획득한 행동 단계 합계
              ÷ 해당 원칙의 최대 단계 합계
              × 100

해당 원칙의 최대 단계 합계 = 평가된 선택 수 × 4
```

### 에피소드 종합 점수

```text
종합 점수 = 해당 에피소드에서 실제 평가된 원칙별 점수의 산술평균
```

국가 윤리원칙은 원칙 간 고정 우선순위를 제시하지 않는다. 따라서 현재 모델은 임의 가중치를 두지 않고 동일 가중 평균을 사용한다. 해당 에피소드에서 평가하지 않은 원칙은 0점으로 넣지 않고 계산에서 제외한다.

### 수행 구간

| 정규화 점수 | 교육용 해석 |
| ---: | --- |
| 75-100 | 안정적으로 실천 |
| 50-74 | 기준을 이해하는 중 |
| 25-49 | 추가 연습 필요 |
| 0-24 | 우선 점검 필요 |

결과 화면의 엔딩은 사용자가 즉시 이해할 수 있도록 `Good End`(75-100), `Normal End`(50-74), `Bad End`(0-49)로 단순화한다. 세부 수행 구간과 원칙별 점수는 `점수 분석 보기`에서 확인한다.

이 구간도 정부가 정한 등급이 아니다. 학습 피드백을 제공하기 위한 프로젝트 내부 기준이며, 사용자 연구와 전문가 검토 후 조정해야 한다.

## 7. 법률 자료의 사용 범위

AI 기본법은 윤리원칙의 법적 근거와 사업자 의무를 확인하는 데 사용한다.

- 제27조: 인공지능 윤리원칙 제정과 교육·실천방안의 근거
- 제31조: 고영향 AI·생성형 AI 이용 사실의 사전 고지와 생성물 표시
- 제32조: 일정 기준 이상 AI 시스템의 위험 식별·평가·완화와 사고 대응
- 제33조: 고영향 AI 해당 여부의 사전 검토
- 제34조: 고영향 AI의 위험관리, 설명, 이용자 보호, 사람의 관리·감독, 문서화
- 제35조: 고영향 AI가 기본권에 미치는 영향평가 노력과 취약계층 특성 반영

다만 다수 조항의 직접 수범자는 인공지능사업자다. 게임 이용자의 한 번의 선택을 근거로 `법 위반`이라고 표시하지 않으며, 결과 화면에는 `법률 참고`로만 제시한다.

## 9. 구현 기술

- `js/scoring-engine.js`: 브라우저와 Node.js에서 함께 실행되는 순수 JavaScript 진단 엔진
- 원칙별 독립 평가: 선택 하나에 여러 원칙별 0-4단계 저장
- 정규화: 선택 수가 다른 원칙을 동일한 0-100 범위로 변환
- 설명가능성: 점수, 획득 단계, 최대 단계, 정책 코드, 법률 참고를 함께 출력
- 행동 데이터 분석: 선택 이유, 응답 시간, 위험·적극 실천 비율, 사전·사후 변화, 반복 학습 횟수 집계
- 학습자 유형 분류: 전체 점수와 위험 선택 비율, 가장 낮은 원칙을 조합한 설명가능 규칙 기반 분류
- 버전 관리: 점수 모델 변경 시 기존 기록과 분리
- 자동 검증: 22개 장면과 61개 선택지의 평가 누락, 잘못된 원칙, 범위 밖 점수를 테스트

## 10. 선택 데이터 분석 모델

현재 모델은 설명가능 규칙 기반 모델이다. `js/analysis/` 아래의 독립 모듈이 특징 추출, 원칙 점수 계산, 학습자 유형 분류, 다음 콘텐츠 추천을 각각 담당하고 `js/analysis/learning-model.js`가 결과를 통합한다. 각 선택 뒤에 판단 이유를 구조화해 기록하고, 장면을 읽은 뒤 선택하기까지 걸린 시간을 함께 저장한다. 별도 데이터베이스 컬럼을 만들지 않고 `user_episode_progress.history`와 `assessment` JSON에 저장한다.

분석 결과는 다음과 같다.

- 위험 선택 비율: 행동 수준 0-1 선택 수 / 전체 선택 수
- 적극 실천 비율: 행동 수준 3-4 선택 수 / 전체 선택 수
- 평균 고민 시간: 유효한 선택 응답 시간의 평균
- 주요 판단 기준: 권리·검증·후속 행동·편의·관계·불확실 중 최다 응답
- 생각 변화: 사전·사후 문항의 0-4 행동 수준 차이
- 데이터 충분도: 선택 수와 판단 이유 응답률에 따른 낮음·보통·높음 표시
- 학습자 유형: 전체 수행률, 위험 선택 비율, 취약 원칙을 조합한 규칙 기반 유형

이 분석은 행동 로그를 요약하는 교육용 분석이며 심리검사나 머신러닝 예측 결과가 아니다. 생성형 AI API를 연결하는 것만으로 직접 학습한 모델이라고 설명하지 않는다.

### 10.1 모델 처리 단계

1. 특징 추출: 선택 수, 위험·적극 실천 비율, 판단 이유 응답률, 평균 반응 시간, 사전·사후 변화, 원칙별 최저·최고 점수와 편차를 계산한다.
2. 유형 분류: 위험 선택 비율을 먼저 확인하고, 전체 수행률과 원칙 간 편차, 가장 낮은 원칙을 조합해 유형을 분류한다.
3. 기록 충분도 계산: 선택 데이터 50%, 판단 이유 응답률 25%, 사전·사후 응답 15%, 반복 학습 10%로 기록 충분도를 계산한다. 분류 정확도나 통계적 신뢰 확률이 아니다.
4. 맞춤 추천: 가장 낮은 원칙에 연결된 다음 행동을 제안하고 분류에 사용된 규칙을 화면에 공개한다.

통합 모델 버전은 `2.0.0`이며, 각 모듈의 버전과 분류 근거를 결과에 함께 남긴다. `tests/learning-model.test.js`에서 특징 추출, 위험 유형 분기, 원칙별 유형 분류, 추천 결과를 자동 검증한다.

## 11. 학습 패턴 군집분석 확장

후속 연구는 다음 순서로 진행한다.

1. 사용자의 명시적 동의를 받아 선택 패턴과 사전·사후 응답을 수집한다.
2. 에피소드 완료, 7대 원칙 점수, 판단 이유, 응답 시간, 사전·사후 응답이 모두 있는 기록만 선별한다.
3. 버전 3의 완료된 기록을 학습자별 한 행으로 합치고, 조건을 충족한 독립 학습자 50명 이상일 때 K-means로 비슷한 응답 패턴을 탐색한다. 중복 학습자, 누락·무한대·범위 밖 값은 거부한다. 50명은 내부 파일럿 기준이지 통계적 타당성의 보장이 아니다.
4. 각 군집의 취약 원칙, 위험 선택 비율, 생각 변화를 요약한다.
5. 취약 원칙에 맞는 교수자용 수업 활동과 관찰 기준을 제안한다.

이 절차는 `ml/cluster_learners.py`로 구현되어 있다. 기준에 미달하면 스크립트가 오류와 함께 종료된다. 합성 데이터는 대시보드 시연에만 사용하고 실제 군집분석에는 포함하지 않는다.

생성형 AI는 자유서술 응답의 문장 정리나 개인화 설명에 보조적으로 사용할 수 있지만, 핵심 점수는 검증 가능한 정책 기반 규칙에서 산출한다.

## 12. 한계와 검증 과제

- 루브릭 단계와 수행 구간은 프로젝트 팀의 교육용 조작화이므로 전문가 내용타당도 검토가 필요하다.
- 현재 점수는 표준화된 윤리 역량 검사나 심리검사가 아니다.
- 학습 효과를 주장하려면 실제 사용자의 사전·사후 결과와 통계적 검증이 필요하다.
- 원칙 간 갈등이 있는 상황은 평균 점수만으로 충분히 설명되지 않을 수 있으므로 결과에서 원칙별 점수를 함께 제시한다.
- 정책과 법령이 개정되면 근거 코드, 설명, 루브릭 버전을 함께 갱신해야 한다.
