# twAIve 최종 오류 수정 및 검증 결과

작업일: 2026-10-08. 대상은 만 14세 이상 중·고등학생용 교육 프로토타입입니다. 실제 학생 대상 운영 적합성을 인증한 문서는 아닙니다.

## 기능 오류 수정

| 발견 사항 | 적용한 수정 |
| --- | --- |
| 다른 계정에 이전 기록이 남음 | 로그인·로그아웃 때 전체 학습 상태, 캐시, 저장 상태를 분리하고 이전 세션의 요청·타이머 결과를 무시 |
| ‘처음으로’가 기록을 덮어씀 | 홈 이동은 저장하지 않음. 다시 플레이만 확인 후 새 학습을 시작하고 시작 직후 기존 기록을 지우지 않음 |
| 실패한 저장을 성공으로 안내 | 저장 중·완료·실패를 상단에 표시. 실패한 당시 기록으로 재시도. 미저장 상태로 로그아웃·창 닫기 시 경고 |
| 저장 후 상단 점수가 늦게 바뀜 | 저장 성공 즉시 평균 점수 표시만 갱신. 입력·AI 답변이 있는 화면은 다시 그리지 않음 |
| 서버 읽기 실패 뒤 빈 기록으로 재시작 | 읽기 실패를 ‘기록 없음’과 구분. 기존 기록 보호를 위해 시작을 멈추고 다시 확인 제공 |
| 사후 질문 전 완료 처리 | 엔딩 장면과 사후 응답이 모두 있어야 완료 기록으로 저장 |
| 늦은 AI 응답이 다른 리포트에 표시 | 요청 당시 계정·화면을 확인하고 화면 이동 시 취소. 응답의 점수·엔딩도 요청 당시 값 사용 |
| 중복 클릭·늦은 전환으로 화면이 되돌아감 | 인증 버튼 처리 중 비활성화, 장면 전환 취소, 판단 이유 요청의 세션·선택 확인 |
| 세션 복원 시 별명이 예전 정보로 바뀜 | 로그인 세션 복원은 저장된 프로필을 읽기만 하고 인증 메타데이터로 덮어쓰지 않음 |
| 연결이 멈췄을 때 무한 대기 | Supabase HTTP 요청 15초, 이유 요청 10초, AI 설명 클라이언트 45초 및 서버 요청별 제한 적용 |

DB 요청 제한은 개별 HTTP 요청 기준입니다. 전체 인증 SDK 내부 재시도까지 항상 15초 이내라는 보장은 아닙니다. 저장 재시도 버튼은 상단 독립 줄로 배치해 결과 버튼에 가려지지 않게 했습니다.

## 10대 대상 표현과 AI

- 실패 엔딩을 ‘다시 연습 · 다음에는 다르게 해보기’로 바꾸고, 분석은 이번 선택에 대한 연습 포인트로 한정했습니다. 성격이나 정신건강 진단이 아닙니다.
- ‘데이터 신뢰도’를 ‘기록 충분도’로 바꿨습니다. 기존 계산값을 정확도 확률로 해석하지 않습니다.
- 기본 판단 이유는 행동을 안전하다고 보증하지 않는 중립 문구입니다. 모든 장면에서 ‘맞는 이유가 없거나 아직 잘 모르겠어’를 선택할 수 있습니다.
- 자유 질문을 네 가지 결과 질문 선택으로 제한했습니다. 서버도 허용된 질문만 받습니다. 이름·학교·상담 내용을 자유롭게 적어 전송하는 경로를 줄였습니다.
- 생성된 설명·이유에 Moderation 검사를 추가했습니다. 위험 콘텐츠·검사 실패·형식 오류는 기본 교육 설명이나 중립 이유로 대체합니다. 이 조치가 모든 위험 출력을 제거한다는 보장은 아닙니다.
- AI 설명은 짧은 문장과 섹션으로 표시하고 기존 밝은 글자색을 유지합니다. 외부 영상은 출처와 내용을 확인하도록 안내합니다.
- 서버 인스턴스별 사용자당 분당 12회 제한을 추가했습니다. 서버리스의 여러 인스턴스에 걸친 총량 제한이나 비용 상한은 아닙니다.

## 디자인 및 성능

로그인·회원가입의 GmarketSans, 클릭해서 넘어가는 로고 화면, 이미지 없는 로그인 폼, 같은 화면에서 열리는 결과 상세, 분석·AI 두 개 탭, 학습 이동 버튼을 유지했습니다. 작은 화면 입력 글자는 16px로 두어 확대 위험을 줄였습니다. iOS 실제 키보드 검증은 별도로 필요합니다.

5개 에피소드와 로고에 WebP를 추가했습니다. 첫 화면의 이미지·로고 합계는 약 4.7MB에서 약 720KB로 줄었습니다. PNG 원본은 보존했습니다. `#405b7c`, `#6c7e94`는 사용하지 않습니다.

## 개인정보 및 연구 분석

운영자는 사용자가 제공한 `twAlve 프로젝트 팀`, 삭제·문의 연락처는 `yeeun7117@sookmyung.ac.kr`, 보유 기간은 1년으로 반영했습니다. 표시 이름은 별명으로 안내합니다. 회원가입은 만 14세 이상 확인과 약관·개인정보 처리 확인을 요구하며 연구 동의는 마이페이지에서 별도로 선택합니다. 체크박스는 신원·연령 인증이나 법정대리인 동의 검증을 대신하지 않습니다.

교수자 집계는 점수 버전 3만 사용하도록 SQL을 수정했습니다. 웹도 오래된 집계 함수의 응답을 거부해 서로 다른 기준의 점수를 섞지 않습니다. 사이트 배포만으로 DB 함수가 업데이트되지는 않습니다.

K-means는 별도 오프라인 분석입니다. 동의·완료·버전 3·중복 없는 익명 학습자·유효 범위·결측 없음 조건을 확인하고 독립 학습자 50명 미만이면 중단합니다. 동일한 학생의 에피소드를 여러 표본으로 세지 않습니다. 모든 패턴이 같으면 중단하며 CSV 출력에서 식별자와 추가 열을 제외합니다. 50명은 탐색적 파일럿 기준이지 모델 타당성의 증거가 아닙니다. 점수 계산의 원칙별 0~4 루브릭과 공식은 이번 오류 수정에서 바꾸지 않았습니다.

## 검증 근거

- Node 자동 테스트 12개 파일: 채점, 기록·리포트, 인증, 세션 전환, 지연 읽기·쓰기, 저장 실패·재시도, 이전 AI 응답 폐기, API 검증·안전·시간 제한.
- Python 테스트 4개: 동의·완료·버전·독립 학습자, 값 범위·누락, 동일 패턴 처리, 합성 입력으로 군집 산출과 식별자 제외. 합성 테스트는 실제 학생 학습이나 타당성 검증이 아닙니다.
- Chrome Playwright: 5개 에피소드의 실제 버튼 완주, 사후 응답 후 저장, 저장 실패·재시도, A/B 계정 분리, 재로그인 후 5개 결과 복원, 읽기 실패 후 기록 보호, 이전 AI 응답 폐기.
- 로그인·회원가입은 320×568부터 1440×900 및 가로 화면까지 7개 크기. 리포트는 320~2560px 7개 폭에서 가로 넘침 없음. AI 생성 결과 표현의 최소 글자 대비 10.52:1 확인.
- 브라우저 기능 검증은 모의 계정·모의 DB·모의 API를 사용했습니다. 실제 서비스 계정의 기록을 덮어쓰거나 유료 OpenAI 호출을 실행하지 않았습니다.
- 실제 Vercel·GitHub Pages의 새 Chrome 세션에서 CDN·Supabase 초기화, 로고·이미지, 클릭 인트로, 로그인·회원가입, 정책을 확인했으며 페이지 오류가 없었습니다. 실제 로그인 이후 저장·생성형 답변 성공 여부까지 검증한 것은 아닙니다.
- 운영 Supabase에 교수자 집계 함수 마이그레이션을 적용했습니다. 점수 버전 3·독립 학습자 집계 필드와 익명 사용자의 실행 차단을 SQL로 확인했고, 사용자가 재로그인한 최신 Vercel 앱에서 실제 교수자 통계가 정상 표시됨을 확인했습니다. 확인 당시 참여자 12명, 완료율 31.7%(19/60), 군집분석 조건 충족 학습자 1명이었습니다. 학생 기록을 변경하거나 삭제하지 않았습니다.

`supabase/migrations/20261008_teacher_dashboard_v3.sql`은 2026-10-08 운영 DB에 적용 완료했습니다. 기존 관리자 로그인 세션으로 집계 함수만 교체했으며 접근 권한은 확대하지 않았습니다. 이전 점수 기준의 기록도 DB에 보존되지만 현재 교수자 통계에는 포함하지 않습니다. 웹과 DB 버전을 함께 맞추지 않아 발생한 교수자 통계 오류는 실제 화면에서 복구를 확인했습니다.

1. OpenAI 계정의 미성년자 관련 데이터 보유 설정과 실제 처리 지역 확인. `store:false`만으로 Zero Data Retention 적용을 보장하지 않습니다. [OpenAI 미성년자 안내](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance), [데이터 관리 안내](https://developers.openai.com/api/docs/guides/your-data).
2. 1년 경과·삭제 요청에 대한 실제 삭제 작업과 백업 처리, 동의 철회 대응. 자동 삭제 예약은 이번 코드 배포로 설치되지 않습니다.
3. API의 분산 사용자 한도·예산 경보, 교사 검토 영상 목록, 일러스트·로고 사용 권한, 위험 상황 신고·사람 도움 연결 절차 확정.
4. 최신 탭에서 성인 심사자용 테스트 계정으로 실제 AI 응답·저장 복원을 한 번 리허설. 실제 로그인과 교수자 통계는 확인했으나 생성형 답변·학습 기록 저장까지 이번 운영 DB 확인에서 검증한 것은 아닙니다. 실제 학생 개인정보 대신 가상 기록으로 시연하고 장애 대비 화면 녹화를 준비.

남은 운영 설정이 확인되기 전에는 ‘공개 청소년 서비스의 모든 안전·법적 검증을 끝냈다’고 소개하지 않습니다. 정책 근거와 계산 설명은 [심사 변경 설명](DEFENSE_UPDATE_2026-10-07.md), [점수 계산 문서](SCORING_MODEL.md)를 사용하세요.

## 약관·개인정보처리방침 보완

- 사용자 확인에 따라 일러스트·로고의 AI 생성 사실을 기재하고, 독점적 저작권 확보를 보증하지 않도록 작성했습니다. 폰트·SDK는 별도 외부 라이선스 자료로 구분했습니다.
- Supabase 운영 프로젝트 설정에서 일본 도쿄(`ap-northeast-1`)를 확인했습니다. DB 지역만 확인한 것이며 다른 서비스·로그·백업 위치를 확인했다고 주장하지 않습니다.
- 계정에 연결된 원본 기록, 식별정보를 분리한 연구 자료, 집계 통계를 구분했습니다. 기본 교수자 집계는 연구 동의와 별개이며 연구 대상 집계는 동의가 필요하다는 실제 동작을 명시했습니다.
- 1년 보유 기준, 삭제·처리 중단·연구 동의 철회, AI 자동 이유 추천과 요청형 결과 설명, 브라우저 인증 저장, 외부 호스팅·CDN·영상 전송을 보완했습니다.
- 빈 입력 표시는 제거했지만, 미확인 국외 이전 세부 조건과 자동 파기 운영은 완료 사실로 바꾸지 않고 별도 주의 문구로 남겼습니다.
