# 실제 사용자 데이터 기반 학습 패턴 분석

이 디렉터리는 학생에게 정답 유형을 붙이는 분류 모델이 아니라, 응답 특성이 비슷한 학습자 집단을 탐색하고 집단별 AI 윤리 지도 활동을 제안하는 군집분석 파이프라인이다.

## 분석 전 조건

1. 사용자가 마이페이지에서 익명 연구 활용에 동의한다.
2. 에피소드를 완료하고 7대 원칙 점수, 판단 이유, 응답 시간, 사전·사후 응답이 저장된 기록만 사용한다.
3. 분석 조건을 충족한 실제 기록을 50건 이상 수집한다.
4. 합성 데이터와 동의하지 않은 기록은 실제 분석에 포함하지 않는다.

50건은 졸업작품의 탐색적 파일럿 기준이며 전체 학생에게 일반화할 수 있는 표본 수를 의미하지 않는다. 기준에 도달하기 전에는 정책 기반 개별 피드백과 집계 통계만 제공한다. 기존 계정의 동의를 일괄 변경하지 않고 사용자가 직접 동의한 기록만 사용한다.

## 입력 특징

`data/training-data-template.csv`의 열 구조를 사용한다.

- 대한민국 인공지능 윤리원칙 기반 7대 원칙 점수
- 선택 시 가장 많이 사용한 판단 이유
- 평균 응답 시간
- 사전·사후 변화
- 위험·적극 실천 비율
- 익명 연구 활용 동의
이름, 아이디, 이메일, 비밀번호는 분석 데이터에 포함하지 않는다. 정답 라벨이나 전문가 라벨도 사용하지 않는다.

## 실행

```powershell
python -m pip install -r ml/requirements.txt
python ml/cluster_learners.py ml/data/learner-data.csv --output ml/artifacts
```

## 출력

- `learner_clusters.csv`: 익명 기록별 군집 번호
- `cluster_summary.json`: 군집별 인원, 취약 원칙, 평균 위험 선택, 생각 변화, 지도 활동
- `learner_clusterer.joblib`: 동일한 특징 구조에 적용할 전처리기와 K-means 모델

군집은 학생을 고정된 성격으로 판정하는 진단 결과가 아니다. 교수자가 공통적인 학습 어려움을 파악하고 수업 활동을 설계하기 위한 탐색적 보조 자료로만 사용한다.
