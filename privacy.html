문의·삭제 요청

3. 교수자 통계와 선택적 연구 활용

  • 권한이 있는 교수자는 참여자 수, 완료율, 문항별 위험 선택 비율, 원칙별 점수, 사전·사후 변화 등 집계 통계를 볼 수 있습니다. 교수자 화면은 이용자의 이름·아이디·개별 답변을 제공하지 않습니다.
  • 이 기본 집계는 학습 서비스의 운영·점검을 위한 것으로, 연구 동의 여부와 별개입니다. 연구 동의자 수와 모델 검증에 활용할 수 있는 데이터의 준비 현황은 따로 구분합니다.
  • 선택적 연구의 목적은 졸업 연구의 학습 패턴 분류 모델 검증입니다. 활용 항목은 선택·이유·응답 시간, 원칙별 점수, 사전·사후 응답과 완료 정보입니다. 연구용 자료를 만들 때에는 아이디·별명·내부 인증용 이메일을 제외하고, 필요한 경우 연구용 식별자로 바꿔 사용합니다.
  • 서비스 원본은 사용자 식별자로 계정과 연결되어 있어 완전히 익명인 정보가 아닙니다. 식별정보를 분리한 연구 자료도 재연결 가능성이 있으면 가명정보이며, 완전한 익명정보와 다릅니다.
  • 연구 동의는 기본 미동의이며, 마이페이지에서 선택·철회할 수 있습니다. 체크를 해제하고 프로필을 저장하면 이후 연구 대상 집계에서 제외됩니다. 거부·철회해도 학습 이용에는 불이익이 없습니다.
  • 철회만으로 기존 연구용 사본이 자동 삭제되는 기능은 없습니다. 별도 사본의 이용 중단·삭제도 요청하려면 문의 이메일로 알려주세요. 이미 개인을 다시 구별할 수 없게 익명화한 통계는 개인별 분리·삭제가 어려울 수 있으며, 처리 가능 범위와 결과를 안내합니다.
  • 이 동의는 OpenAI의 모델 학습을 위한 동의가 아닙니다. 식별 가능한 개별 기록을 연구 목적 외로 공개·제공하는 근거로 사용하지 않습니다.

4. 외부 서비스와 국외 처리

웹 화면 제공, 인증·저장 및 AI 기능에 다음 외부 서비스를 사용합니다. 현재 운영자는 학습 기록을 광고 목적으로 판매하거나 제공하지 않습니다. 외부 처리와 기술 접속 로그는 별도로 확인해야 합니다.

Supabase · 인증과 DB
계정·인증 정보, 프로필과 학습 기록을 처리합니다. 로그인·저장·조회 시 HTTPS로 전송하며, 현재 프로젝트 DB 지역은 일본 도쿄(ap-northeast-1)입니다. 이는 확인한 DB 지역이며 모든 서비스 로그·백업의 위치를 보장하는 표시는 아닙니다. Supabase 개인정보 정책
Vercel · 웹 화면과 AI 서버
웹 화면과 AI 서버 함수를 제공합니다. AI 기능 요청 시 로그인 토큰과 위의 요청 데이터를 서버가 처리하고, 토큰은 Supabase에서 확인합니다. 접속 IP·브라우저·요청 시각 등의 기술 정보가 인프라 로그에 처리될 수 있습니다. Vercel 개인정보 정책
GitHub Pages · 별도 웹 배포
GitHub Pages 주소로 접속하면 GitHub가 정적 웹 화면을 제공합니다. 계정·학습 DB는 Supabase에, AI 요청은 Vercel 서버에 연결됩니다. 웹 호스팅 과정에서 접속 정보가 처리될 수 있습니다. GitHub 개인정보 정책
OpenAI API · 이유 추천과 결과 설명
위의 AI 요청 항목과 생성된 답변의 안전 검사 내용을 HTTPS로 전송합니다. 별명·아이디·내부 인증용 이메일·사용자 식별자·비밀번호·로그인 토큰은 OpenAI 요청 본문에 포함하지 않습니다. API 요청에 store:false를 설정하지만, 이것만으로 모든 로그가 남지 않거나 즉시 삭제되는 것은 아닙니다. 공식 문서상 기본 악용 방지 로그는 통상 최대 30일이며 예외가 있을 수 있습니다. 현재 프로젝트의 Zero Data Retention 적용은 확인되지 않았습니다. OpenAI API 데이터 처리 안내
Google / YouTube · 학습 영상
영상 검색에는 AI가 만든 학습 주제 검색어를 사용하며 계정 아이디나 원본 학습 기록을 검색어에 넣지 않습니다. 영상 썸네일을 불러오거나 영상·검색 링크를 열면 브라우저 접속 정보가 Google / YouTube에 전달될 수 있습니다. Google 개인정보 정책
jsDelivr · 폰트와 라이브러리
Gmarket Sans·Pretendard 폰트와 Supabase 브라우저 SDK 등 공개 파일을 불러옵니다. 파일 요청 시 IP와 브라우저 정보 등의 접속 메타데이터가 CDN에 전달될 수 있으며, 학습 기록을 파일 요청 내용으로 보내지는 않습니다. jsDelivr 개인정보 정책

국외 이전 확인 현황: Supabase DB의 일본 저장은 확인했습니다. 다른 서비스의 실제 처리 국가, 계약상 수탁자 법인·연락처, 재위탁·백업·기술 로그의 보관 기간 및 국외 이전의 적용 근거는 아직 확인 중입니다. 위 서비스 정책 링크만으로 해당 고지·동의 절차가 완료되었다는 뜻은 아닙니다. 학생 대상 공개 모집 전에 실제 계약·프로젝트 설정을 확인하고 필요한 고지·동의 절차를 보완해야 합니다.

외부 전송을 원하지 않으면 접속·학습을 중단하고 문의 이메일로 처리 중단·삭제를 요청할 수 있습니다. 결과 설명을 요청하지 않으면 그 결과 설명용 전송은 발생하지 않지만, 스토리 선택 뒤 이유 추천은 자동 요청될 수 있습니다. 현재 외부 AI 전송만 끄는 별도 설정은 없습니다.

5. 보유 기간과 파기

운영자가 정한 계정·학습 기록 및 해당 기록에서 만든 연구 자료의 최대 보유 기간은 1년입니다. 계정은 가입일, 학습 기록은 기록 생성일, 연구용 사본은 원본 기록의 보유 기한을 기준으로 합니다. 재생성·복사만으로 보유 기간을 연장하지 않습니다. 문의 메일은 요청 처리 종료 후 삭제하는 것을 원칙으로 합니다.

  1. 기간 만료, 처리 목적 종료 또는 유효한 삭제 요청을 확인하면 운영자가 삭제 대상 계정·기록과 별도 사본의 범위를 확인합니다.
  2. 본인 확인 후 Supabase 인증 계정을 삭제하면 연결된 프로필·학습 기록도 함께 삭제되도록 DB를 구성했습니다. 특정 기록만 삭제하는 요청과 연구용 사본은 해당 범위를 따로 처리합니다.
  3. 운영자가 관리하는 전자 파일은 복구·재이용되지 않도록 삭제하고, 종이 사본을 만든 경우 파쇄 등으로 파기합니다. 처리 결과 또는 처리할 수 없는 사유를 요청자에게 안내합니다.

현재 확인되지 않은 운영 항목: 보유 기간 만료 자료를 자동으로 삭제하는 작업의 운영 적용, 문의 메일·연구용 별도 사본의 정기 점검, 외부 서비스 백업·기술 로그의 삭제 기간입니다. 1년 보유 기준이 설정되어 있다는 이유로 자동 파기가 이미 운영되고 있다고 안내하지 않습니다.

법령상 보관 의무가 있는 자료가 발생한 경우에는 해당 근거·항목·기간을 별도로 안내하고, 일반 학습 목적의 이용과 구분합니다. 현재 유료 결제에 따른 거래 기록 보관은 없습니다.

8. 브라우저 저장과 접속 정보

Supabase SDK가 로그인 유지·세션 갱신을 위해 인증 세션을 브라우저의 로컬 저장소(localStorage)에 저장할 수 있습니다. 로그아웃하거나 브라우저의 해당 사이트 데이터 삭제 기능으로 지울 수 있으며, 저장을 차단하면 로그인 유지가 제한될 수 있습니다. 공용 기기에서는 이용 후 로그아웃하세요. 현재 앱 코드에는 별도의 광고·행동 추적 도구를 추가하지 않았지만, 호스팅·CDN·인증 서비스의 기술 접속 정보 처리는 위 외부 서비스 항목과 각 정책을 함께 확인해야 합니다.

9. 분석의 범위와 안전성 확보

원칙별 점수·선택 패턴 분석은 교육용 피드백입니다. 이용자의 실제 성격·정신건강을 진단하거나 학교 성적·선발·징계 등 권리에 중대한 영향을 미치는 결정을 내리는 용도로 제공하지 않습니다. 점수 근거와 AI 설명에 관한 문의는 팀 이메일로 접수할 수 있습니다.

  • 비밀번호 인증은 Supabase Auth를 이용합니다.
  • 프로필과 학습 기록은 로그인한 본인의 사용자 식별자에 따라 접근하도록 Row Level Security 정책을 적용합니다.
  • OpenAI와 YouTube API 키는 Vercel 서버 환경변수에만 저장하며 브라우저 코드에 포함하지 않습니다.
  • AI 이유 추천과 결과 설명 서버는 Supabase 로그인 토큰을 확인한 뒤 요청을 처리합니다.
